#### 1. 可视化工作流（Workflow）

- **零代码拖拽**：像搭积木一样编排 AI 步骤Dify。
- 支持：条件分支、循环、API 调用、数据库查询、多模态（文 / 图 / 语音）Dify。
- 例子：用户提问 → 查知识库 → 生成回答 → 自动翻译 → 发送邮件。
    
#### 2. 企业级 RAG（私有知识库）

- 上传 PDF/Word/PPT/Excel 等**20 + 格式**，自动解析、分片、建向量库Dify。
- **私有部署**：数据不出境，精准回答内部资料，**降低幻觉**。
- 支持：混合检索、元数据过滤、引用溯源。

#### 3. Agent 智能体（自动任务）

- 自主拆解复杂任务、**调用工具**（联网搜索、API、数据库）、多轮思考。
- 内置 50 + 插件，支持自定义插件开发Dify。
- 例子：“帮我查今天西安天气，写一段推荐语，生成配图”。

#### 4. 全模型兼容（统一网关）

- 支持**200 + 模型**：GPT-4o、Claude、Llama 3、DeepSeek、Qwen、本地 Ollama 等Dify。
- 兼容 OpenAI API 标准，**一键切换模型**，对比效果Dify。
- 成本优化：智能路由，**降本 30%-50%**Dify。

#### 5. LLMOps（监控 + 运维）

- 全链路日志、Token 统计、成本分析、用户反馈闭环。
- 企业级：RBAC 权限、审计日志、数据隔离、SSO 登录Dify。

### 🧩 五种应用类型（开箱即用）

1. **聊天助手**：客服机器人、个人助理（如 GPT）。
2. **文本生成**：文案、摘要、翻译、代码生成。
3. **Agent 应用**：自动执行复杂任务（如数据分析、报告生成）。
4. **Chatflow**：带记忆的对话流程（如多轮对话、引导式问答）。
5. **Workflow**：无记忆的自动化流程（如数据处理、定时任务）。




视觉推理：简单说就是：让 AI 不只 “看懂画面里有什么”，还要能 “根据画面做逻辑推导、算数学、理解关系、预测下一步”。 它比普通看图（分类、检测）更高阶，是从像素到逻辑的能力。

融合推理（Fusion Reasoning），简单讲：把两种或多种不同来源、不同类型的信息 / 模型 / 推理方式 “揉在一起”，互相补短板，得出更准、更稳、更像人的结论。
